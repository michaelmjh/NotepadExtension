# Sticky Notes

Five colour-coded sticky notes in a browser popup, with autosave. Manifest V3, Edge and Chrome.

## Install

1. Open `edge://extensions` (or `chrome://extensions`) and turn on **Developer mode**.
2. Click **Load unpacked** and pick this folder.

## Sync with Duck Dashboard

When Duck Dashboard (michaelmjh/EdgeDashboard) is installed in the same browser, its new tab notes and these notes stay in sync both ways, live. After installing both, click **Reload** on Sticky Notes once so it introduces itself to the dashboard.

`background.js` handles the link and only accepts messages from the dashboard's fixed ID (`kgnlnhdenhgddbggpccmpodgogfhkggh`).
